# Lattice measurements (experimental)

Measured line extrema/spacing and calibrated 2-D FFT magnitude diagnostics.
Spatial frequency is cycles per metre (or per pixel if geometry unknown), not
radians/m; no 2π factor is added. Profile peak SD and SEM are reported
separately. **Does not select or reduce a primitive 2-D basis**, so the known
2× vector discrepancy on TClTAP and Z/Δf_t consistency remain open. The old
`lattice_analysis.py` source was not attached for equivalence checking.
